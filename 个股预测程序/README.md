# 个股涨跌概率预测程序

把**技术面、基本面、资金面、情绪面、宏观、消息面、周期、金融理论**八大维度的信息，
压缩成统一的"因子"，再按**周期权重矩阵**汇总，推导出个股在未来
**1天 / 5天 / 10天 / 20天 / 1个月 / 1个季度 / 半年 / 1年** 的
**涨跌概率与涨跌幅度**。

同一套 `core/` 内核同时服务两种运行方式：

| 运行方式 | 入口 | 适用场景 |
|---|---|---|
| **本地网页版** | `streamlit run app.py` | 电脑/手机浏览器，交互式看图表与因子明细 |
| **本地命令行版** | `python run_local.py 600519` | 批量跑、生成报告、放进定时任务 |
| **线上版（手机可用）** | 本仓库直接部署到 Streamlit Cloud | 见 [DEPLOY_STREAMLIT.md](DEPLOY_STREAMLIT.md) |

## 二、预测是怎么做出来的（四层结构）

```
   ┌────────────────────────── 取数层 ──────────────────────────┐
   │ 日/周/月K线 · 实时快照 · 大盘指数 · 资金流 · 财务 · 股东    │
   │ 两融 · 龙虎榜 · 板块 · 新闻公告 · 宏观 · 商品价格           │
   │ 多源容错：任一源失败自动降级，全部失败才降级到合成数据       │
   └───────────────────────────┬───────────────────────────────┘
                               ▼
   ┌──────────────────────── 因子层 ───────────────────────────┐
   │ 11 个分析模块各自输出统一结构的 Factor：                     │
   │   id / 中文名 / 类别 / 方向(±1) / 强度 / 可信度 /            │
   │   观测值 / 中文解读 / 理论依据 / 适用周期                    │
   │ 典型产出量：100~130 条因子                                  │
   └───────────────────────────┬───────────────────────────────┘
                               ▼
   ┌────────────────────── 概率推导层 ─────────────────────────┐
   │ ① 按周期加权汇总因子 → 方向分 score ∈ [-1,1]               │
   │ ② logit(p) = logit(先验) + k_周期 × score × 证据充分度      │
   │ ③ σ_周期 = 理论扩散 ⊕ 该股历史区间分布 ⊕ 经验先验           │
   │ ④ E[r] = Φ⁻¹(p_up) × σ × 可预测性折扣                     │
   │ ⑤ AI 模型（逻辑回归 + 梯度提升 + 历史相似形态类比）融合      │
   └───────────────────────────┬───────────────────────────────┘
                               ▼
   ┌────────────────────── 校准与报告层 ───────────────────────┐
   │ 多周期一致性检查 · 历史回测 IC/胜率 · 置信度自动折扣         │
   │ 文本/HTML 报告 · 7 类图表 · JSON 导出                       │
   └───────────────────────────────────────────────────────────┘
```

### 2.1 因子：全项目唯一的"通用货币"

任何一个模块的任何一个观察，最终都要变成一个 `Factor`：

```python
Factor(id="ma_alignment", name="均线多头排列", category=Category.TECH,
       direction=+1, strength=0.82, reliability=0.90,
       value="MA5>MA10>MA20>MA60", detail="短中长期均线依次向上发散…",
       theory="道氏理论/均线系统", horizon=("d1","d5","d10","d20"))
```

* `direction`：+1 看涨 / -1 看跌 / 0 中性
* `strength`：方向上的强度 0~1
* `reliability`：**我对这条因子有多大把握**（数据缺失、样本不足、逻辑间接时下调）
* `horizon`：只对指定周期生效（如日线 MACD 金叉只管短线）
* 登记在 `config.CONTRARIAN_FACTOR_IDS` 里的因子（散户情绪、人气排名等）
  会被引擎自动**翻转方向**——它们看涨时反而是风险。

### 2.2 周期权重矩阵：什么周期听谁的话

`core/config.py` 里为三种周期类型定义了不同的大类权重：

| 大类 | 短线(1~10天) | 中线(20天~1季) | 长线(半年~1年) |
|---|---|---|---|
| 技术面 | **1.00** | **1.00** | 0.60 |
| 资金面/主力 | **1.05** | 0.90 | 0.70 |
| 情绪/博弈 | 0.80 | 0.60 | 0.45 |
| 基本面 | 0.35 | 0.95 | **1.15** |
| 宏观/行业 | 0.30 | 0.60 | **1.00** |
| 消息/事件 | 0.70 | 0.55 | 0.40 |
| 周期/季节 | 0.40 | 0.55 | 0.70 |
| 理论模型 | 0.55 | 0.75 | 0.85 |
| 个股特性/阶段 | 0.60 | 0.65 | 0.75 |
| AI 模型 | 0.90 | 0.85 | 0.60 |

还可以对**单个因子**精调，例如 `d1` 周期下 `capital_main_net=1.35`、
`valuation_percentile=0.15`（一天之内估值高低几乎不影响涨跌）。

### 2.3 概率与幅度为什么自洽

很多"预测程序"的通病是：给一个 90% 的看涨概率，却配一个 ±0.1% 的幅度。
本程序用同一套分布推导两者：

```python
sigma = σ_日 × √bars ⊕ 该股历史上"持有 bars 天"的真实收益标准差
exp_ret = norm_ppf(p_up) × sigma × 可预测性折扣      # 折扣随周期递减 0.42→0.38
ci = exp_ret ± 0.90 × sigma
p_big_up = 1 - Φ(阈值; exp_ret, sigma)
```

所以概率越大、期望幅度越大，且区间永远覆盖合理波动范围。

<details>
<summary><b>⑨ 分析理论依据</b></summary>

| 理论 | 实现方式 | 局限性（已在报告中标注） |
|---|---|---|
| **道氏理论** | 多周期均线水位+方向 5 项表决判主要趋势，摆动点结构判次级趋势，成交量验证，吸筹/拉升/派发阶段 | 均线法滞后；对参数敏感 |

| **斐波那契理论** | 250 日高低点回撤位（0.191~0.809）+ 扩展位（1.272~2.618）+ 时间窗 | 属自我实现的预言，仅大市值标的有意义 |
| **江恩理论** | 角度线（1×8~8×1）、四方形、时间周期 | **经验性方法，置信度上限 0.45** |
| **混沌理论** | R/S 重标极差分析算 Hurst 指数，D=2-H，Rosenstein 法估 Lyapunov | 短样本下偏差大；样本<120 直接返回保守值 |
| **量价时空理论** | 8 种经典量价配合矩阵 + 时间维度（是否处于时间窗、涨跌持续时间） | 不同市值/流动性下阈值差异大 |
| **扇形原理** | 从关键点画 1×1~8×1 角度线，判断跌破/站上 1×1 | 锚点选择敏感 |
| **百分比回撤** | 1/8 分数体系 + 1/3 体系，共 9 档 | 与斐波那契位高度重合 |
| **多周期共振** | 日/周/月各判趋势，同向共振/反向背离 | 月线样本少，噪声大 |
| **缠论（简化）** | 分型→笔→线段→中枢，MACD 面积比较判背驰，1/2/3 类买卖点 | 简化实现，结构自洽但不完整 |
</details>

## 四、AI 部分：从历史走势中学习规律

`core/mlmodel.py`，**纯 numpy 实现，不需要 scikit-learn**：

* **53 个特征**：动量（1/3/5/10/20/60 日）、摆动指标、波动率、均线偏离与排列、
  价格位置、量能、量价相关、OBV 斜率、布林 %B、跳空、涨停、相对大盘强度/相关/Beta
* **3 个模型**
  * `LogisticModel`：L2 正则 + **时间衰减样本权重**（半衰期 250 根，近期样本更重要）
  * `GBDTModel`：直方图梯度提升树（32 箱、深 2、最多 60 棵、子采样）
  * `KNNPatternModel`：**历史相似形态类比**——在标准化特征空间找历史上最相似的
    40 个时点，用它们后续的真实收益加权投票
* **严格因果**：所有特征只用第 t 根及之前的数据。项目里有一条自动化测试
  （`verify_all.py` 中的"特征/规则分因果性检查"）会把序列截断一半重新计算，
  要求前半段特征**逐位完全一致**——这是防止未来函数泄漏最有效的手段。
* **前向验证**：扩展窗口 walk-forward，逐段训练逐段测试，报告真实样本外
  AUC / 命中率 / Brier / IC
* **基准率校准**：模型原始概率会被训练期"上涨样本占比"带偏，
  用 log-odds 平移把概率重新锚定到 50%
* **规则分作为特征注入**：把逐根 K 线计算的规则分当作 AI 的输入特征之一，
  让模型学到"在什么市场状态下规则模型更准"，这是"理论 + 机器学习"结合的关键

## 五、诚实的局限：这个程序**不**能做什么

这一节比上面所有内容都重要。

1. **它不能稳定预测涨跌。** 程序内置的回测会如实告诉你这一点。
   在真实数据上（8 只大市值 A 股、1600 根日线）本程序的规则分
   RankIC 约为 **-0.01 ~ 0.00**，即**几乎没有预测能力**；
   回测模块会据此把 8 个周期的置信度大幅折扣，并给出
   **"D（历史不成立）"** 的评级。这不是 bug，这是对市场有效性的正常反映。
2. **技术指标的预测力在学术上一直很弱。** 短周期约 50~53% 的方向胜率，
   扣除交易成本后基本不剩什么。程序输出接近 50% 的概率时，
   它其实是在正确地告诉你"看不清楚"。
3. **它无法应对黑天鹅。** 模型只能从历史规律外推，
   对突发政策、地缘冲突、财务造假这类没有历史样本的事件无能为力。
4. **数据可能缺失或错误。** 免费行情接口存在延迟、缺失、口径差异；
   程序会尽可能标注降级情况（报告里的"数据说明"区块），
   但**不应该把输出当作精确事实**。
5. **长周期预测的不确定性极大。** 1 年期的 72% 概率区间通常在 ±20% 以上，
   这个宽度本身就说明"1 年后的价格"基本不可预测。
6. **它不是投资建议。** 请把它当作一个**信息汇总与风险提示工具**：
   帮你快速看清一只股票当前的技术位置、资金动向、估值水平、
   消息面对比和多空证据清单——而不是一个算命机器。

每个模块都可以独立自测（离线、不联网）：

```powershell
python -m core.indicators      # 51 个指标的数值校验
python -m core.patterns        # 30 种 K 线形态
python -m core.technical       # 技术面因子合成
python -m core.mlmodel         # AI 训练/预测 + 因果性检查
python -m core.forecast        # 概率引擎自洽性
python -m core.backtest        # 回测 + 随机信号对照
python -m core.charts          # 7 类图表生成
python -m core.report          # 报告生成
python tests/test_app_logic.py # 界面逻辑（streamlit stub，无需安装 streamlit）
```

## 七、常见问题

**Q：分析很慢（30~60 秒）？**
A：主要在等网络取数（十几个接口）和 AI 训练。可以关闭"启用 AI 模型"，
或把"历史数据天数"调小。

**Q：某些数据取不到？**
A：免费接口有区域/时段限制。点"数据源健康检查"看具体哪一项失败；
程序会自动降级并在报告里标注。完全没网时可用**演示模式**。

**Q：能预测港股/美股吗？**
A：支持 `00700.HK` / `AAPL` 格式，但港股美股走 yfinance 兜底，
且基本面/资金面模块是 A 股口径，结果参考价值有限。

**Q：为什么概率总是接近 50%？**
A：因为大多数时候**确实看不清楚**。当因子严重冲突或证据不足时，
程序会诚实地输出接近 50% 的概率并降低置信度，这比给出 90% 的假信心更有用。

**Q：置信度为什么这么低？**
A：置信度会被历史回测结果折扣。如果这只股票的历史回测显示信号无效，
置信度就会被压到 20~30%。这是特性，不是缺陷。
